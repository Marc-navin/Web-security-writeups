## Web Application VAPT Assessment Report

This repository contains a technical vulnerability assessment report documenting multiple security weaknesses identified during web application security testing.

The assessment covers several vulnerability categories, including Cross-Account Session Confusion, Stored Cross-Site Scripting (XSS), HTML Injection, Server Information Disclosure, Deprecated PHP Version Disclosure, and Insufficient Password Policy Enforcement.

The report documents the identified vulnerabilities, testing observations, potential security implications, and recommended remediation measures to help improve the application's overall security posture.

**Key Areas Covered:**
- Authentication and Session Management
- Cross-Site Scripting (XSS)
- HTML Injection
- Server Information Disclosure
- Outdated Software and Version Disclosure
- Password Policy and Account Security

**Objective:** To identify security weaknesses, evaluate their potential impact, and provide actionable recommendations for strengthening web application security.
